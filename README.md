# Analysis of Large Language Models' Narrative Construction Across Languages: A Comparative Study of English and Italian Event Descriptions

This repository contains the source files and data for the master’s thesis **“Analysis of Large Language Models' Narrative Construction Across Languages: A Comparative Study of English and Italian Event Descriptions”**, submitted to Politecnico di Torino in October 2026 by Chiara Casale.

The thesis examines how three LLM-based chatbots (ChatGPT, Mistral, Qwen) describe politically polarising protest events under different prompt, language, and output conditions. It compares neutral, protester-critical, authority-critical, and headline-generation requests in English and Italian across three protest cases: Iran (December 2025–January 2026), anti-ICE protests in the United States, and the Askatasuna eviction protests in Turin, Italy.

## Repository structure

- `Similarity.ipynb` – Contains the code used to compute the similarities and produce the Excel files containing them.  
- `excel-similarity` – It is a folder with 6 Excel files of computed similarities, divided by language and model.
- `graph` – It is a folder contained the 6 box plots of the similarities.
- `diagram.pdf` – It contains the research diagram.
- `repetitions-pdf` – It is a folder containing 6 pdf with all the repetitions of the answers.
- `first-answers.zip` – It is a zip file containing the 72 first answers, each in a txt file, which where analyzed in OpenQDA.
